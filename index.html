🎮 Unity 官方与引擎

CLI Pipeline package leaves all scenes open after builds
discussions.unity.com08/07

Unity Pipeline 包 v0.4.0-exp.1 的实锤 bug：任何 player 构建跑完后，构建列表里的所有场景会被 additive 叠开在编辑器里。已经把 CLI 管线接进日常构建的先确认自己版本——这种副作用配上构建后的自动化脚本，很容易误伤工程。

Customizable Main Toolbar: Unity 6.7 improvements
discussions.unity.com08/07

可定制主工具栏的一批改进已经进 6.7，下个 Alpha 就能拿到，主要是元素分组和开关的可见性。工具栏塞满自定义按钮的人值得先看下新的分组行为再迁配置。

The 3D as 2D sample project, Bunny Blitz, is available now
unity.com08/05

官方放出的「3D 当 2D 用」示例工程 Bunny Blitz，可直接下载拆。想用 3D 资产做 2D 表现的项目，扒它的相机与渲染设置比读文档快。

Why Model Importer not support removing identical meshes? I write this options for everyone
discussions.unity.com08/06

有人自己补了 Model Importer 的「导入时合并相同网格」选项并公开了实现。Unity 默认把一个 FBX 里的重复实例当独立 mesh 导入，场景美术摆一片植被/道具就是白吃内存和包体——大场景项目值得直接抄。
