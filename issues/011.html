本周主线是 Unity 7 落地带来的版本分叉——CoreCLR 路线、Entities Write Groups 弃用、Input System 改走 core package，升级计划都得重算；AI 侧最可照抄的是官方那条「概念图 + Unity CLI 让 agent 搭出能跑的 UI Toolkit 菜单」的示范。

🎮 Unity 官方与引擎

Unity 7 is here
discussions.unity.com10/06

Unity 7 落地的官方论坛帖。对还在 6000.x 上的项目，这意味着 6.7 LTS 之外又多出一条主干线，升级路线图得重新算一遍。帖子本身信息很短，真正的细节要配着同期的 CoreCLR 进展和包体变更一起读。

CoreCLR, Scripting, and .NET Update, October 2026
discussions.unity.com10/05

Unity 官方给 .NET 现代化路线的 10 月进度，接 3 月/6 月两次更新和技术升级指南往下走：CoreCLR 的受支持发布锚在 6.7 LTS 与 Unity 7 这条线上。打算吃 CoreCLR 性能红利的，这篇决定你该停在哪个版本上等。

Entities - Write groups deprecated in 7.0
discussions.unity.com10/06

Entities 在 6000.7.0b3 把 Write Groups API 标成 deprecated，文档里却没给替代机制——帖子就是在追问「那换成什么」。用 DOTS 且靠写组做 system 互斥的项目，现在就该盯这个线程，别等真升级那天才发现一堆系统要重写。

Unity Announces External Dependency Manager Package
unity.com09/29早报提过

Unity 推出官方 External Dependency Manager（EDM），接替社区时代的 EDM4U 管 Android/iOS 原生 SDK 依赖。接过广告/登录/内购 SDK 的都吃过 EDM4U 的版本冲突，迁到官方维护这条线值得早排。

🤖 AI × 游戏开发

Meeting you where you work: Unity Plugin for Grok Build
unity.com10/01早报提过

官方 Unity Plugin 现在也能装进 Grok Build，同一套 30+ 条 Unity 自写 skill，一条终端命令装完，要求 Unity 6+。继 Claude Code 和 Codex 之后的第三个宿主——说明这套 skill 是宿主无关的，换 agent 不必重建工作流。

The Agent Said It Was Done. The Database Disagreed.
huggingface.co10/03早报提过

Agent 报告「做完了」，数据库说没有。重度让 agent 跑改动的人该把它当验收清单读：你判断完成的依据是 agent 的自述，还是真实落地的副作用。

This is the first time I’ve coded myself without AI in a year, and I feel both amazing and incredibly sad.
reddit.com10/06

一位大厂工程师的自述：岗位要求每件事都走 AI，一年没自己写过代码，这次手写完「既爽又难受」。不是 AI 怀疑论，而是一份关于手感流失的一手观察——如果你的 Unity 代码也一年没亲手敲过，值得照着照镜子。

Microsoft’s New AI-Powered Patents Offer Little to Be Excited About | 30/09/26
aiandgames.com09/30早报提过

AI and Games 拆了微软新公开的几项游戏 AI 专利，结论是噱头大于实质。当祛魅材料读，省得被「大厂已经在用 AI 做游戏」的二手转述带着跑。

Sega won't "entrust the creative aspect of games to AI," but is using tech to "improve efficiency" in other departments
gamesindustry.biz10/06

世嘉的表态：创作部分不交给 AI，但在发行等部门用它提效率。大厂把线画在哪里，对你谈外包和发行时的预期管理有点参考——也仅止于此，别指望更多细节。
